# bo2map.py Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `tools/bo2map.py` proposes Burnout 3 ↔ Burnout 2 function pairs with confidence and evidence.

**Architecture:** `tools/bo2src.py` loads Burnout 2 (CSVs, source bodies, header vtables) into `Fn2` records.
`tools/bo2map.py` loads Burnout 3 via `xref.load()` into `Fn3` records, runs the anchor-and-propagate matcher, and
holds the CLI. Pure functions over plain records, so tests use synthetic fixtures.

**Tech Stack:** Python 3 standard library only, host-side (no container), `unittest` like `test_progress.py`.

**Spec:** `docs/superpowers/specs/2026-10-08-bo2map-design.md`

## Global Constraints

- Burnout 2 checkout passed as `--bo2 PATH`; nothing from it is copied into the repo.
- Output `build/bo2map.tsv` (gitignored); never writes `symbol_addrs.txt`.
- Thresholds: order/call size ratio within ±50%; `medium` needs size within ±25%; vtable region 0x4DDAA0–0x4E0680.
- No commits unless the user asks (CLAUDE.md).

## Review Focus

- Overloaded Burnout 2 names (same `Class::method` twice): must not pair the wrong overload silently → pair by order.
- Burnout 3 functions with no counterpart (most of them): alignment must gap, not force pairs.
- A constant shared by unrelated functions: uniqueness check on both sides before seeding.
- Missing generated asm (`configure.py` not run): exit with xref's message, not a traceback.
- Burnout 2 path wrong: clear error naming the missing CSV.

### Task 1: Burnout 2 loader (`tools/bo2src.py`)

**Produces:** `Fn2(addr:int, size:int, name:str /* Class::method or plain */, file:str, callees:set[str],
strings:set[str], floats:set[float])`; `demangle(sym:str) -> str` (MW: `m__<n>ClassF…` → `Class::m`, `__ct`/`__dt`
→ `Class::Class`/`Class::~Class`, plain names unchanged); `definitions(text:str) -> list[(qualname, body)]`;
`vtables(bo2:Path) -> dict[class, list[method]]` (slot order); `load(bo2:Path) -> list[Fn2]` sorted by address,
game only.

- [ ] Tests: `demangle("FExist__13CGTFileSystemFPCc") == "CGTFileSystem::FExist"`, `demangle("__ct__9CGameModeFv")
  == "CGameMode::CGameMode"`, `demangle("main") == "main"`; `definitions` on a snippet with two methods, a comment
  containing `{`, and a string containing `}` returns both bodies; callee extraction skips `if/for/while/switch/
  return/sizeof`; float literal `0.85f` is extracted; header-comment vtable parse yields `CGameMode` slots
  `Init, Enter, Exit, Destroy, Update, …`.
- [ ] Implement; run `python3 tools/test_bo2map.py`; all pass.
- [ ] Real data: `load()` returns >1,300 functions including `CGameMode::Init` and `CGTFileSystem::FExist`.

### Task 2: Matcher (`tools/bo2map.py`)

**Consumes:** `Fn2`, `demangle`, `vtables`. **Produces:** `Fn3(addr, size, name, unit, calls:set[int],
strings:set[str], floats:set[float])`; `Pair(a3:int, n2:str, kinds:set[str])`; `match(f3:list[Fn3], f2:list[Fn2],
vt3:list[list[int]], vt2:dict) -> dict[int, Row]` where `Row` has `fn2`, `kinds`, `confidence`, `conflict`.
`align(sizes3, sizes2) -> list[(i,j)]` (Needleman–Wunsch, free end gaps).

- [ ] Tests: `align` of `[0x40,0x100,0x8,0x200]` vs `[0x40,0x8,0x1F0]` pairs (0,0),(2,1),(3,2) and gaps 0x100; name
  seed → `high`; order-only pair within 25% → `medium`; a function reached by order and call → `high`; two
  candidates → both `low` with `conflict`; vtable slot alignment pairs the remaining slots; call propagation skips
  an ambiguous callee.
- [ ] Implement; tests pass.
